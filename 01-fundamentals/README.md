# Module 01 — Fundamentals

Before writing a single query, you need a mental model of what a database actually
is, the different flavors that exist, and how a database management system is put
together internally. This module builds that foundation.

## Lessons

1. [What Is a Database?](01-what-is-a-database.md)
2. [Types of Databases](02-types-of-databases.md)
3. [DBMS Architecture](03-dbms-architecture.md)

## Learning goals

By the end of this module you can:
- Explain the difference between data, a database, and a DBMS
- Name the major database categories and pick the right one for a scenario
- Describe the layers a query passes through inside a database engine
