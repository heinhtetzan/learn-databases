# Module 04 — Schema Design

You know the theory (Module 02) and the query language (Module 03). Now you'll
apply both to design a real, non-trivial schema from a plain-English brief, and
learn the common mistakes to avoid.

## Lessons

1. [ER Modeling](01-er-modeling.md)
2. [Case Study: Designing a Bookstore Schema](02-case-study-bookstore.md)
3. [Schema Anti-Patterns](03-antipatterns.md)

## Learning goals

By the end of this module you can:
- Translate a plain-language requirement into entities, attributes, and relationships
- Model one-to-many and many-to-many relationships correctly
- Recognize and avoid the most common real-world schema mistakes
