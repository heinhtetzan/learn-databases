# Module 07 — NoSQL

Relational databases aren't the right fit for everything. This module covers the
major NoSQL categories, what each is actually good at, and gives you a concrete
framework for choosing between SQL and NoSQL for a real project.

## Lessons

1. [NoSQL Overview](01-nosql-overview.md)
2. [Key-Value & Document Stores](02-key-value-and-document-stores.md)
3. [Column-Family & Graph Stores](03-column-family-and-graph-stores.md)
4. [SQL vs. NoSQL: A Decision Guide](04-sql-vs-nosql-decision-guide.md)

## Learning goals

By the end of this module you can:
- Explain what "NoSQL" actually means (and what it doesn't)
- Describe each major NoSQL category's data model and best-fit use cases
- Make and justify a SQL-vs-NoSQL choice for a given real-world scenario
