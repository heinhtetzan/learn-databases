# Module 02 — Relational Model

The relational model is the theory behind SQL databases: tables, rows, columns,
keys, and the rules that keep data consistent. This module gives you the vocabulary
and design principles you'll use for the rest of the course.

## Lessons

1. [Relational Model Basics](01-relational-model-basics.md)
2. [Keys & Constraints](02-keys-and-constraints.md)
3. [Normalization](03-normalization.md)

## Learning goals

By the end of this module you can:
- Describe a database using correct relational terminology (relation, tuple, attribute)
- Choose appropriate primary and foreign keys, and explain referential integrity
- Normalize a messy table up to Third Normal Form (3NF), and explain why you would (or wouldn't)
