# Module 09 — Security & Administration

Designing and querying a database is only part of the job — running one safely
in production requires access control discipline and a real backup/recovery
plan. This module covers both at a practical level.

## Lessons

1. [Database Security Basics](01-security-basics.md)
2. [Backup & Recovery](02-backup-recovery.md)

## Learning goals

By the end of this module you can:
- Apply the principle of least privilege to database users and roles
- Explain SQL injection and how parameterized queries prevent it
- Describe backup types and calculate RPO/RTO for a recovery plan
