# Module 10 — Capstone Project

Time to put all nine modules together on one realistic system, end to end:
requirements → ER model → SQL schema → sample queries → indexing → transaction
safety → a NoSQL/scaling discussion → a security and backup plan.

## Lessons

1. [Project Brief](01-project-brief.md) — the requirements you'll design against
2. [Solution Guide](02-solution-guide.md) — a full worked solution, don't peek early!

## How to use this module

1. Read the [brief](01-project-brief.md) only, and attempt every task yourself
   first — on paper, in a text file, or in a real database.
2. Only after attempting it, open the [solution guide](02-solution-guide.md) to
   compare your design against a full worked answer, with reasoning at every
   step referencing the exact lesson each decision came from.

This is the single best way to find out what actually stuck from the last nine
modules — treat it like a real project, not a reading exercise.
